    Method

    Community colleges first. A program is listed only when a public catalog or official college page confirms it. Grants come from official college pages, press releases, ED/DOL announcements and the NSF Award Search. The map shows AI programs only; AI grants are listed in the Grants tab. Dot color shows the highest AI credential a college offers (certificate, associate degree or bachelor's degree). Colleges whose AI program start year we couldn't source appear only in 2026, the latest year. Programs whose launch year still needs confirmation are left off the map and the table until it is confirmed. Universities are not pinned in this community-college view. Dotted lines connect two colleges with a documented partnership, such as a shared project or grant, a transfer pathway, or NAAIC membership or mentorship. A line is drawn only when a public source documents it. Any record without a source link and an as-of date is dropped at build time. No tracking, cookies, logins, third-party requests or student data.

    How this map is updated

    Updates are not automatic. New AI programs, grants and partnerships are gathered as candidates, and each one is checked against its public source before it is added. A person then reviews and approves each new version before it is published, so the map changes in reviewed batches rather than in real time. The date at the top of the page shows the latest update.

    Data sources

    • IPEDS (NCES): college names and locations (HD2024, public domain).
    • NSF Award Search API: NSF awards.
    • College catalog and program pages, college and press-release grant announcements, consortium pages (linked per entry).
    • Base map: us-atlas v3 (ISC license), derived from U.S. Census Bureau cartographic boundary files (public domain). Drawn into the page at build time.
